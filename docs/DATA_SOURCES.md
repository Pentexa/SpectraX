# SPHEREx Data Inventory

14 November 2026. IRSA published SPHEREx DR1 with spectral images from Surveys 1–2 and the 102-channel All-Sky Cube. QR3 covers spectral images from Surveys 3–4. Both releases are searchable through IRSA SIA2. DR2 was planned for December 2027, and the IRSA schedule gave no date for DR3. The API returns release status and empty data lists for both. The IRSA SIA2 query with `COLLECTION=spherex_dr1` and `POS=circle 269.45 4.7 0.002` returned 240 image records. The two selected images have distinct observation times in their FITS headers. The API derives wavelength and bandwidth from the LVF WCS at each pixel. A detector layer shows one nominal channel or combines all 17 channels using a mean weighted by the number of contributing pixels. Each pixel in the combined image reports the contributing channel count, the total NHITS value, and the combined FITS flags. [SPHEREx Explanatory Supplement](https://irsa.ipac.caltech.edu/data/SPHEREx/docs/SPHEREx_Expsupp.pdf)

The `COLLECTION=spherex_qr3` query at the same position returned 123 image records. The verified QR3 cutout overlaps about 93.8% of the October 2025 DR1 cutout after quality masking. The API shows the pair side by side. The comparison tolerance and the manifest's calibration rule prevent subtraction for this pair. Cite the QR3 image using DOI [10.26131/IRSA662](https://doi.org/10.26131/IRSA662). [IRSA Quick Release citation guidance](https://irsa.ipac.caltech.edu/data/SPHEREx/docs/overview_qr.html)

### Verified comparison

For a 0.04° field, 94.0% of pixels overlap after geometric alignment and quality masking, and 90.4% also pass the wavelength compatibility check. The five common sources had a median relative position offset of 0.17 arcseconds and an RMS scatter of 1.27 arcseconds. The surface-brightness difference at the center pixel was `+0.0249 ± 0.0320 MJy/sr`, with uncertainty from the FITS variance. At the same coordinate, 100 channels are valid in the cube spanning all six detectors. The two channels with `NHITS=0` are returned as `null`. ### Citation and use

These public data are available without credentials. SPHEREx is a NASA mission led jointly by JPL and Caltech. IRSA asks authors to cite DOI [10.26131/IRSA678](https://doi.org/10.26131/IRSA678) for the images and [10.26131/IRSA679](https://doi.org/10.26131/IRSA679) for the cube, and to include the mission acknowledgment in published work.
