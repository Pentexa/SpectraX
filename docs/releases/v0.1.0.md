The first SpectraX backend release uses live NASA/IPAC IRSA SPHEREx services for archive searches and new cutout downloads. The prepared images and spectral cube come from FITS files published by IRSA. The setup verifies them against SHA-256 checksums. [IRSA data access](https://irsa.ipac.caltech.edu/spherex-archive-documentation/spherex-data-access/)

- Search DR1 and QR3 by position, time, and wavelength, then import FITS cutouts.
- Compare observations with WCS alignment, measure source photometry, and inspect 102 channels and six detector layers from the DR1 cube.
- Retry transient archive errors, enforce a shared disk quota, and clean up incomplete downloads.
- Validate releases with end-to-end tests on real DR1 and QR3 FITS files, a live IRSA search, and manifest checks on new downloads.

Spectral coverage in this release is limited to the DR1 cube listed in the manifest. The API returns empty values for channels outside coverage or masked by quality flags. It also reports publication status for DR2 and DR3. [Data inventory](https://github.com/Pentexa/SpectraX/blob/v0.1.0/docs/DATA_SOURCES.md)

The container image is `ghcr.io/pentexa/spectrax-api:v0.1.0`. See the [README](https://github.com/Pentexa/SpectraX/blob/v0.1.0/README.md) for setup and API usage.
